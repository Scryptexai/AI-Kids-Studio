## Cara Kerja & Aktivasi GitHub Actions Zernio

1. Pastikan 2 GitHub Repository Secrets sudah terpasang di **`Scryptexai/AI-Kids-Studio` → Settings → Secrets and variables → Actions**:
   - `ZERNIO_API_KEY`: API key dari dashboard Zernio (`https://zernio.com/api/v1`)
   - `ZERNIO_YOUTUBE_ACCOUNT_ID`: `accountId` kanal YouTube yang terhubung di Zernio (opsional otomatis dicari lewat `GET /v1/accounts` bila dikosongkan)
   - `ZERNIO_PLAYLIST_ID` *(opsional)*
2. Begitu branch ini di-*merge* ke `main` (atau dijalankan langsung lewat tab **Actions → Upload & Schedule YouTube 4x/Day (Zernio) → Run workflow → `BATCH_READY`**):
   - Runner `ubuntu-latest` mengunduh ketujuh master MP4 (`KT-S01`..`KT-S06` + `KT-L01`) dari Google Drive,
   - Memverifikasi ukuran byte + `SHA-256` + provenance render `ai-kids-studio-3d-cpp` + thumbnail JPEG `< 2 MB`,
   - Meminta URL `POST /media/presign`, mengunggah MP4 & thumbnail via `PUT`, lalu memanggil `POST /posts` lengkap dengan `Idempotency-Key` dan `scheduledFor` + `timezone: "Asia/Makassar"`,
   - Zernio langsung mengunggah ke YouTube sebagai *scheduled private* dengan `publishAt` asli YouTube pada jam **Pagi (`08:00`), Siang (`12:30`), Sore Long (`16:30`), dan Malam (`20:30`) WITA**, lalu mencatat statusnya ke `upload/published.json`!
