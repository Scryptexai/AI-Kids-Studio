# Formula C for Minecraft: "How you built X" (the evolution ladder)

Adapted 2026-11-12 from Formula C in the cartoon skill (`cartoon-3d-short/references/formula-evolution-ladder.md`,
measured on two ~14M-view shorts: the beach bunker and the door). Study only: never copy their lines.
Gap check 2026-11-12: no Minecraft short found using this ladder. The closest is long-form "Upgrading House From
Dirt to Diamond" (36.9M), which shows that the upgrade ladder already pulls Minecraft viewers.

## Why this one is steadier than the what-if formula
The what-if formula lives or dies on ONE surprising answer: same channel, same format, 559 views to 16.9M.
The ladder doesn't need a surprise. Retention comes from **the build changing every 4-6 s**, and every viewer has
lived the struggle (mobs at night, zombies at the door, empty farms). No formula always works, but this one has a
floor: even a weak ladder is a satisfying build timelapse.

## The idea in one line
"You" start with the most primitive version of a known Minecraft build. One mob (or one game rule) keeps beating it,
each fix is a real block or mechanic, and step by step it becomes the build everyone knows. The last line names it.

## Structure (30-40 s version: 95-120 words, ~3.2 words/s)
| # | Beat | Time | Template |
|---|---|---|---|
| 1 | Hook: primitive version + goal | 0-3 s | "If you [primitive act] so [goal], you have a [primitive name]." |
| 2 | Rungs ×4-5 | 3-28 s | "But [mob / rule beats it, visibly]. So you [verb + block + where]. This is a [Minecraft name]." |
| 3 | Twist rung | ~last 10 s | "That [odd detail] isn't by mistake. [The real game rule in one line]." Answers "why is it built like that?" |
| 4 | Cosy tag | ~4 s | List of three: two normal drops/items, the third a **real Minecraft trivia fact** as the joke. |
| 5 | Payoff | last 2 s | "Congratulations, you have built a [build]." Cut on the last word, loops to the hook. |

A 55-65 s version (160-200 words, 6-7 rungs) is allowed, but start with 30-40 s: the what-if hit proved ~30 s works
in this niche.

## Rules
- **Every rung is a real game rule, tested in-game** before the script is final (edition + version noted; Java and
  Bedrock differ). The comments will correct you if a rung is wrong, so a wrong rung kills trust.
- **Jokes = real Minecraft facts**, not invented gags (the creeper started as a pig model with its size numbers mixed up;
  the ghast sounds were recorded from C418's cat; cats scare creepers; phantoms come after 3 nights without sleep).
  Write the source next to each fact (Minecraft Wiki page).
- Second person, present tense. Connectors alternate **So / But / Except**, never "and then".
- Every failure is **physical and visible**: a mob walks in, a door gets broken, a farm stays empty, a creeper blows a hole.
- Every fix is **a block + a place**: "an iron door with a button", "water streams into one hole", "slabs on the roof".
- A **false relief** now and then ("Clever." "Much better.") right before the next failure.
- Name about every second rung ("This is a kill chamber."). Use the community's real names (spawning floor, drop
  chute, AFK spot, kill chamber) because viewers recognise them.
- **One antagonist for the whole ladder**: one recognisable mob with a **name tag** (in-game name tags show above its head),
  e.g. a zombie called "Gerald" who beats every version until the last.
- Escalation: each failure is sneakier than the last; the final fix is the least obvious one.
- House rules still win: VO flows with no pauses, each line's picture lands on its word, recorded SFX only,
  captions as a separate green-screen clip, final file named by the title.

## Picture (Replay Mod)
- **ONE build that grows.** Build every stage in a test world and save a copy (or `/clone` the stages side by side),
  so each rung is recorded on the same spot.
- Each rung = **failure shot + build shot**. Failure: the mob does the thing (slowed with `/tick rate`). Build: a
  fast-forward block-placing timelapse (the what-if creator calls fast-building clips their most engaging hook footage).
- **Cutaway views** for anything hidden: spectator mode through the ground for caves, x-ray-style side cuts.
- Camera always moving: Replay Mod paths between rungs, hard cuts only on hits/explosions. Intro cuts < 1 s.
- The rung name gets a clean ~1 s hero orbit of the whole build.
- **Ending: big pull-back** to the finished build working at full speed (every past rung visible in it).

## Title + metadata
- "How you invented the [build] in Minecraft" / "How a [primitive] becomes a [build]".
- Description: one sentence + edition/version. Tags: minecraft, minecraft tips, minecraft farm/build.
